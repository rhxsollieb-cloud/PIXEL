# Pixel 本地桌面与像素界面

## 运行

```sh
npm install
npm run desktop
```

`desktop` 先构建界面与后端，然后启动 Electron。已构建时可以使用 `npm run desktop:launch`。`npm run package:win` 生成 `release/Pixel-0.1.0-Windows.exe`，可直接运行，无需安装 Node.js。`npm run dev` 保留浏览器开发入口。

当前保留源码开发模式，不重新打包。持续调整前端使用 `npm run dev`，浏览器界面由 Vite 热更新；检验独立原生窗口时使用 `npm run desktop`。原生版读取本地构建产物，源码变更后关闭窗口并重新运行该命令；`desktop:launch` 只复用上次构建，不宣称原生窗口已实现热更新。

CSS 和普通视图组件可热更新；`App` 组合根修改时整页重新加载，以重新创建已销毁的投影、导航与交互服务。已通过刷新后继续进入详情、返回及项目快照保持一致的运行验证；未提交的界面草稿和导航状态在整页刷新时重置。

桌面版将项目、任务和媒体保存在 `%APPDATA%/Pixel/project`，关闭及再次打开继续使用同一项目。新项目的时间线、片段与素材均为空；已有持久化项目完整保留，不因界面升级删除内容。开发版模型配置读取仓库 `.env`；打包版读取 `%APPDATA%/Pixel/.env`。配置模板见 `.env.example`。密钥只进入后端，界面仅接收必要配置状态。未配置时仍可编辑、导入与预览已有素材。

## 视觉与交互

视觉保留暖白底、深蓝字、有限强调色、本地 Fusion Pixel 12px 字体及直角窗口。像素用于统一栅格、字体、间距与状态，区域以留白和细分隔线组织；字段使用淡底与底线，避免卡片厚边框与硬阴影。默认主界面只有上方 Viewer 和下方 Timeline，另保留当前作品标题与必要原生窗口控件。空 Viewer 显示简短空状态，不展示示例星空或人造波形；版本、色板、手势教程、素材筛选、配置提示与调试 revision 不再常驻。

作品、时间线、片段和素材都通过双击进入详情；右键执行当前对象的命令；拖拽建立已登记的关系。素材库的唯一进入路径是主 Viewer 右键 → 素材库，空预览或已有输出均可。按用户明确要求，该菜单项是 P03 的局部导航例外，只打开当前项目的素材上下文，不提交业务 Action；作品标题双击只进入项目详情，其中不再保留素材库入口。Timeline 工作区空白处右键 → 新建时间线 → 选择模型只创建空 Timeline，不附送首个草稿。已有 Timeline 时间位置右键 → 新建生成草稿，显式创建尚无输出的 Item；Asset 拖到时间位置则创建关联已有素材的 Item。两种能力分别表达生成新内容与放置已有内容，不能增加互换的按钮或拖拽入口。保存反馈、失败及真实任务进度仅在相关状态出现，不以常驻提示或业务工具栏代替对象语法。

桌面详情由宿主创建一个独立原生子窗口。父窗口被原生 Modal 隔离，父 renderer 的导航作用域同时失活。子窗口只有一个 `PixelModalHost`；双击子对象推进其 `ModalNavigator.path`，Esc 先关闭菜单，再返回一层，最后关闭详情窗口。关闭后父窗口恢复可交互。浏览器开发版使用同样的导航逻辑和单一 Dialog，并通过 `inert` 隔离背景。

Viewer 菜单直接打开素材库根层；无子层或菜单时 Esc 关闭，进入库内对象后 Esc 逐层返回。它复用现有独立详情窗口/唯一 Modal，不再先打开项目详情，也不新增侧栏、常驻按钮或第二个弹窗宿主。

库内拖动素材时，当前顶部详情作用域临时展示已有 Timeline 的时间位置及适用 Item 的引用区域；有可复用片段输出时，在库内提供 Item → Library 的来源与目标。这些关系继续经 `DragRegistry` 的既有角色路由提交，不向被隔离的主窗口 drop。无图像引用能力的模型不显示引用区；支持引用时只在已有关系或合法拖拽上下文呈现，Wan 首帧模式的有效上限为一张。

两个窗口读取同一个后端，通过同一 Action 协议提交编辑，通过事件刷新只读投影。窗口操作走窄 preload IPC，不授予 renderer Node.js 或文件系统访问。桌面后端绑定随机 loopback 端口并验证会话 Cookie；项目身份和权限仍由后端注入。

播放指针是当前窗口的时间定位状态。用户在时间标尺点击定位，或拖动指针手柄连续查看当前位置；方向键、Home / End 是同一定位控件的键盘表达。当前位置驱动实际片段预览，音视频按片段内时间与素材偏移定位，没有输出时显示中性空状态。定位不提交 Action，不修改片段位置，不写入项目或启动生成；当前不代表已经实现多轨混音与整条时间线合成。

独立窗口控件位于 Modal 标题栏内部，控件及子元素使用 `no-drag`，防止原生窗口拖动区域截获最小化和关闭点击。详情具有自己的任务栏入口，最小化后可从任务栏恢复；父窗口始终保持 Modal 隔离，不能借最小化绕过当前详情。详情最小化与恢复不改变主窗口原有最大化状态。

Viewer 提前准备当前媒体的导出 ticket，准备完成才允许拖动。原生拖出只消费宿主验证的 ticket，以真实媒体文件调用 Electron `startDrag`；不接受 renderer 提供任意文件路径。ticket 绑定窗口、限时且单次消费，拖出后重新准备以支持再次拖动。

## 设计哲学评审

- 对象及唯一入口：仍为现有 Project、Timeline、Item、Asset；素材库唯一入口改为主 Viewer 右键，登记为用户要求的 P03 局部导航例外；项目详情旧入口移除。模型从 Timeline 工作区空白处的右键菜单选择，新生成草稿在已有 Timeline 时间位置右键创建，已有素材仅经 Asset → Timeline 放置。其他进入、命令、关系与字段编辑保持原语义，窗口控制只控制操作系统窗口。
- 渐进披露与隔离：不增加常驻参数面板；独立详情窗口只显示顶部导航层，父窗口无法在详情打开时编辑或接收 drop。
- 状态与业务边界：项目仅由后端维护；新项目与新 Timeline 不预置创作内容，既有项目保持完整。子窗口具有自己的导航及字段草稿，不复制可写项目状态；字段及模型参数由宿主统一渲染。
- 桌面边界：Electron 是本地宿主；GUI HTTP Action 进入同一 `Workbench` / `ActionExecutor`。正式项目 CLI / Agent 适配器仍待接线；诊断 CLI 仅复用模型执行内核，不等于当前项目的 Action 入口。

## 验证与边界

`npm run typecheck`、`npm test`、`npm run test:ui`、`npm run test:desktop` 分别验证类型、核心业务、浏览器手势及原生窗口。测试不调用付费生成。

Viewer 右键 → 素材库这一新入口已通过类型检查、12 项浏览器交互测试及原生桌面验证。验证包含空预览/已有输出进入、键盘菜单、资产子详情返回、根层 Esc 关闭、旧入口移除、纯导航不改项目快照、背景隔离和同作用域关系操作。原生验证确认空项目真实右键进入独立素材库根层、父窗口禁用及关闭恢复，并继续通过持久化、素材放置、窗口控制与导出检查。此前 91 项核心测试等旧轮记录单独保留在[哲学对齐记录](philosophy-alignment.zh-CN.md)，本轮无核心业务修改，未重复执行。此次入口调整不迁移项目、不调用付费生成、不增加常驻控件，继续保持源码开发模式，不重新打包。

完整撤销重做、项目文件拖入打开、跨窗口对象拖拽 broker、正式项目 CLI / Agent、共享 Action 能力查询与完整时间线合成导出仍未实现。库内的放置、引用和复用在同一顶部详情作用域完成，不代表已经实现跨窗口对象拖拽。原生拖出支持 Viewer 当前的单个媒体文件，尚不进行整条作品的合成。本轮依据与偏移修正见[哲学对齐记录](philosophy-alignment.zh-CN.md)。
